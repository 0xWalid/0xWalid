## What I'm building

**[Artifactory-engine](https://github.com/0xWalid/Artifactory-engine)** — A
practitioner-first, multi-agent security engine that runs locally. Maps and ranks
attack surface, then executes custom tradecraft playbooks against it under enforced
scope. Works with open models, so the whole pipeline stays free to run.

**[CVEs-Foresight](https://github.com/0xWalid/CVEs-Foresight)** — Vulnerability
dashboard that joins NVD records against the CISA KEV catalog, so what's *actually
being exploited* sorts to the top instead of what merely scores high.

**[sslmate_ctsearcher](https://github.com/0xWalid/sslmate_ctsearcher)** —
Certificate transparency search via the SSLMate API. A crt.sh alternative for
mapping external attack surface during recon.
